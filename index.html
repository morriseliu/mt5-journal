识别小贴士

        
    
          
  • MT5 手机端：底部「历史」→ 顶部「持仓」，截取列表（无需裁剪状态栏）。
    • 
          
  • 可以重复上传、截图有重叠也没关系：已记录过的订单会被自动识别为重复。
    • 
          
  • 判重依据：订单号（若可见）；否则 品种 + 方向 + 手数 + 开仓价 + 平仓价 + 平仓时间 + 盈亏。
    • 
          
  • 识别后会用「价差 × 手数」校验盈亏，个别看错的数字会被自动校正并标蓝提示。
    • 
          
  • 首次使用需下载识别引擎（约 5–8 MB），之后会缓存。
    •

☁️ 多设备同步

        
数据加密传输，保存在你自己账号下的私密 Gist。换手机后在新手机填入同一个令牌即可自动恢复全部记录。

        

          

          

          

        

        
自动同步
修改后自动上传，打开时自动拉取

        

        

          
          
          
        

        

          如何获取 GitHub 令牌（约 1 分钟）
          
    
            
  1. 登录 GitHub，打开 这个链接（已预选 gist 权限）。
    或手动：头像 → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic)。
    2. 
            
  2. Note 随便填（如“交易复盘同步”），Expiration 选 No expiration 或 1 年，只勾选 gist。
    3. 
            
  3. 点页面底部 Generate token，复制 ghp_ 开头的令牌（只显示一次）。
    4. 
            
  4. 粘贴到上面「访问令牌」，点「保存并同步」。第一台设备会自动创建私密 Gist。
    5. 
            
  5. 另一台手机：打开同一个网址，填同一个令牌即可，Gist 会被自动找到。
    6. 
          

          
令牌只保存在本机浏览器，不会上传到其它地方。没有 GitHub 账号或网络不通时，可选 Gitee 码云（实验性）：gitee.com → 设置 → 私人令牌 → 生成新令牌，勾选 gists；或使用下方「JSON 备份」手动迁移。
